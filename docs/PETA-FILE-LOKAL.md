# Susunan lokal setelah penyatuan

## Sumber utama

`kelompok-lokal/01-web-utama/` adalah root repositori GitHub. Berisi beranda, tiga game, hasil, content/, assets/, assets-3d/, tools/, docs/, katalog, serta referensi desain. Seluruh file merupakan file asli, tanpa pintasan. `.git` telah dipindahkan ke sini beserta riwayat dan remote GitHub.

Lakukan pengeditan, pengujian, commit, dan push dari folder ini. File web tetap berada di root repositori sehingga Vercel tetap menggunakan susunan yang sama.

## Arsip terpisah

`arsip-lokal/` berada di luar repositori utama. Berisi paket ZIP, screenshot, desain lama, checkout Sites historis, inventaris lama, dan versi sebelum penyatuan yang berbeda. Tidak digunakan web utama atau deployment Vercel. Arsip unik disimpan, bukan dihapus.

## Pembersihan

Salinan kode/aset yang identik di folder induk sudah dihapus setelah isinya diverifikasi. File pendukung yang sebelumnya hanya ada di induk telah digabung ke repositori utama. Folder kelompok 02, 03, dan 04 yang berupa pintasan telah dibuang.

Panduan penambahan variasi: MENAMBAH-VARIASI-GAME.md. Pengorganisasian lokal ini belum di-commit/push dan tidak mengubah deployment publik.
